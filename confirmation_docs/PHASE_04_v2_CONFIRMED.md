### Process snags worth recording

1. **Doctor from host venv hits Docker-network DNS resolution.**
   Default `FALKORDB_HOST=falkordb` is unreachable outside the
   compose network. Two clean paths: (a) run doctor in container
   (`docker compose run --rm mindsos doctor`), or (b) host venv with
   `FALKORDB_HOST=localhost` (FalkorDB published on host port 6379).
2. **Doctor in-container reads `/app/docker-compose.yml` frozen at
   image-build time.** Compose-file drift detection from
   docker-compose-run does NOT see edits to the host's compose file
   without a rebuild. Drift verification (N2) needs either
   (a) `docker compose build mindsos` after each edit, or (b) host
   venv with `FALKORDB_HOST=localhost`. Tester used (b).

   ("Extra data at line 11"). Worked around with a python3 one-liner
   that calls `json.dump`. Tester recipe updated to prefer
