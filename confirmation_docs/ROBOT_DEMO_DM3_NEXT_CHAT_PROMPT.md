- **Live-motion wrapper (G-7)** — reuse `sim/motion.py` LIVE: generate trajectory → run the `MOTION_RULES` checklist → only then stream frames into the stepping sim loop (P-7). **PB-F:** precompute + cache the constrained order menu during rehearsal; demo-time = cache lookup first, live generation only on a miss; a checklist failure on a live miss = an honest motion dont-know.
- **Fault injection (G-8)** — a backend switch that freezes a joint; `diagnose_actuators` *detects* it honestly (commanded vs. actual delta) and records the gap to the brain's own Local `capacity-state` (PB-K — no Global write).
