Capacity gates — four phases (reactive to the selected task)

Phase 1 Profiling + Phase 2 Components (sameness atoms) feed Phase 3 Gating (AND/OR per capacity) into Phase 4 Comparison Capacity (inter-grid: moved, recolored, reflected, rotated · intra-grid: touching, inside). A capacity lights green when its gate passes — equivalently, when its Search token fires (gate data is derived from arc_search.FACETS, the same source as Search). Implication indentation: an indented capacity is implied by the one above it (inside ⟹ touching) — test the parent, the child is known-true (skipped). Per capacity, { }json edits its gate; drag any box; hover an edge to highlight.
