# MindsOS

A 5-layer intelligence system on FalkorDB metagraphs.

This repo is built incrementally via the phased rollout plan in
[`confirmation_docs/PHASE_MAP.md`](confirmation_docs/PHASE_MAP.md).
Each phase ships a small slice (runtime infra, then L1, L2, L0 server, L3,
final vertical slice). The current phase is the active branch.
